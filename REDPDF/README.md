# REDPDF - Генератор киберпанк листов персонажа

Веб-приложение в стиле киберпанк для заполнения и управления листами персонажей для настольных ролевых игр. Пользователи могут заполнять информацию о персонаже онлайн, которая автоматически вставляется в шаблон PDF. Администраторы могут управлять пользователями и листами персонажей.

## Возможности

- Интерфейс в стиле киберпанк с неоновыми цветами и футуристическим дизайном
- Исчерпывающая форма листа персонажа со всеми необходимыми полями
- Создание и управление PDF-файлами
- Система аутентификации пользователей с административными возможностями
- Сохранение и загрузка персонажей
- Отзывчивый дизайн для различных размеров экрана

## Требования

- Node.js (v14 или выше)
- npm или менеджер пакетов yarn
- Шаблон PDF-файла с полями для заполнения (с именем `template.pdf`)

## Установка

1. Клонируйте или загрузите этот репозиторий
2. Перейдите в директорию проекта в вашем терминале
3. Установите необходимые зависимости:

```bash
npm install
```

4. Поместите ваш PDF-шаблон в корневую директорию и назовите его `template.pdf`
5. Запустите сервер разработки:

```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

## Настройка

### Административные учетные записи

По умолчанию приложение включает две административные учетные записи:

- Имя пользователя: `admin1`, Пароль: `admin123`
- Имя пользователя: `admin2`, Пароль: `admin456`

Их можно использовать для входа в административную часть приложения.

### Шаблон PDF

Приложение ожидает PDF-файл с именем `template.pdf` в корневой директории. PDF должен содержать поля формы с именами, которые соответствуют полям в веб-приложении. Например:

- `charName` для имени персонажа
- `charRole` для роли персонажа
- `intellect` для интеллекта
- и т.д.

Приложение автоматически заполняет эти поля данными, введенными в веб-форму.

## Использование

### Вход для администратора

Чтобы получить доступ к форме создания персонажа, вам нужно войти с административными учетными данными. Нажмите кнопку входа и введите имя пользователя и пароль администратора.

### Создание персонажей

После входа в систему вы можете заполнить форму листа персонажа в трех вкладках:

1. **Информация о персонаже**: Основная информация о персонаже, характеристики и навыки
2. **Жизненный путь**: История персонажа, отношения, оборудование и образ жизни
3. **Кибернетика**: Кибернетические импланты и модификации

### Сохранение и загрузка

После того, как вы заполнили лист персонажа, нажмите кнопку "СОХРАНИТЬ PDF", чтобы создать заполненный PDF. PDF будет сохранен на сервере и станет доступен для загрузки. Нажмите "ЗАГРУЗИТЬ PDF", чтобы загрузить текущий отображаемый персонаж.

### Управление персонажами

На вкладке профиля вы можете видеть всех сохраненных персонажей и выполнять действия, такие как загрузка или скачивание их.
